## Страницы, кнопки и поля

| Адрес                  | Содержимое и действия                                                                                                                                                                                                                                                 |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/appliances-catalog`  | Плитка в два столбца. Изображение, название, мощность в Вт, минимальная температура в °C, количество лайков («Интерес»). Ползунок 0–3000 Вт с шагом 50; «ОК» применяет минимальную мощность. Нажатие карточки открывает её в ленте. Нет кнопок удаления для гостя.    |
| `/appliances-feed`     | Открывает первый прибор из текущих результатов; при пустом результате — первый опубликованный из mock. ID не фиксирован в ссылке вкладки.                                                                                                                             |
| `/appliances-feed/:id` | Видео autoPlay/loop/muted/playsInline; название, описание, «Ещё/Меньше», два поля по теме, число лайков. «Далее» открывает следующий ID в текущем списке, на последнем приборе кнопка недоступна. Неизвестный, удалённый или черновой ID не показывается.             |
| `/appliances-draft`    | Третья страница доступна через адресную строку. Фотография и видео с локальным предпросмотром, название, описание, мощность и минимальная температура. Поля заполняются без сохранения. «Опубликовать» недоступна. Обновление страницы восстанавливает mock-черновик. |

`/` открывает плитку. Неизвестный маршрут показывает сообщение об отсутствии страницы.

Нижняя панель содержит четыре пункта: **Лента, Добавление, Плитка, Вход**. Только Лента и Плитка доступны. У недоступных пунктов настоящий атрибут `disabled`, они не выполняют переход при мыши или клавиатуре. Добавление открывается вручную: http://localhost:5173/appliances-draft.
